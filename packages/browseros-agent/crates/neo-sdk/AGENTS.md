# neo-sdk

The Playwright-shaped objects (`Page`, `Frame`, `Locator`, `BrowserContext`, `JSHandle`, `ElementHandle`) an agent script sees inside neo-runtime's QuickJS realm. Read `../NEO_STYLE.md` before changing anything here.

- Runs in QuickJS: ES2023 only, no DOM or Node APIs, and the bundle defines no globals.
- Depends on nothing at runtime; `src/runtime-bridge.ts` is its only link to Rust.
- Events: `src/events.ts` (Playwright's `EventEmitter`, `ChannelOwner`'s listener-count subscriptions, the run's `EventPipe`) and `src/waiter.ts` (`waitForEvent`). `Page` and `BrowserContext` are channel owners; a listener error nobody handles ends the run (`createRun`'s `uncaught`).
- `bun run build` writes `dist/sdk.js`, which neo-runtime embeds. Commit it with every `src/` change; `scripts/neo-check.sh` fails on a stale bundle.
- `src/network.ts` is Playwright's client `Request`, `Response` and `RawHeaders` for `goto`'s answer: `responseFor` builds a whole redirect chain from Rust's `chain` getter, once per guid (`Connection._objects`); `timing()`, `failure()` and `finished()` read Rust's record live, where Playwright's client waits for events. `body()` is a `Uint8Array` subclass with Node `Buffer`'s `toString`, `toJSON` and `equals`.
- `src/js-handle.ts` and `src/element-handle.ts` are Playwright's client `JSHandle` and `ElementHandle`. Evaluation arguments and results pass through Playwright's own serializers, vendored unchanged (`serializeArgument`, `parseResult`); Rust never reads them. `src/vendor-shims.ts` stands in for what QuickJS lacks (`URL`, `Buffer.from`, `atob`, `btoa`) inside those vendored files only.
- Locators are Playwright's: `src/locator.ts` keeps Playwright's method bodies, and every selector comes from `vendor/playwright/`, an unchanged copy at Playwright 26137face. Never edit vendored files; `bun run test` re-hashes them against `vendor/playwright/VENDOR.md`. `tests/goldens/` holds Playwright's recorded selector strings, which neo-runtime's tests compare against.

- Start each ported file's header with `Playwright: \`client/<file>.ts\` \`<Class>\``, list every difference as a `Deviation:` line, and start Neo's own files with `Neo:` (`../NEO_STYLE.md`, Provenance). neo-runtime's `cargo test --test provenance` checks the lines.

Checks: `bun run typecheck` and `bun run test`, then `scripts/neo-check.sh` from `packages/browseros-agent`.

The parity tests (`tests/parity/`) run the same scripts through real Playwright and through Neo on one browser and compare what each script and each page saw: `page-url.test.mjs` runs `tests/scripts/watch-url.js` on one tab; `click.test.mjs` runs each click case on the pages in `tests/pages/`, on fresh tabs, and compares the script's result, the error's kind and the events each page saw; never the error's wording, the call log or retry timing. `pages`, `newPage`, `close` and `bringToFront.test.mjs` each run their `tests/scripts/` script on fresh `tests/pages/tab.html` tabs, Playwright's turn and then Neo's, and compare the values and which tabs each left open, closed or active; Neo opens `newPage` in the background, and its `bringToFront` selects the tab where Playwright's leaves headless BrowserOS's selection as it was, both asserted. `innerText` and `getAttribute.test.mjs` each run one script through `compareMethod` on fresh `tests/pages/element-text.html` pages and compare its values, their types and the rejections' kinds, and that each page kept its markup and focus. `isVisible`, `isHidden`, `isChecked`, `isEnabled`, `isDisabled` and `isEditable.test.mjs` compare booleans, matching, waiting and error categories across Locator, Page and Frame receivers (`tests/pages/element-states.html`, `element-editable.html`); `innerHTML.test.mjs` compares markup on `element-html.html`; `allInnerTexts` and `all.test.mjs` read `element-lists.html`; `toString.test.mjs` compares `toString()`/`description()` of every builder form, and `getByRef.test.mjs` a ref from an `ai` snapshot. `hover`, `dblclick` and `tap.test.mjs` run their receivers on fresh `tests/pages/pointer-actions.html` pages and compare return values, error categories and every pointer, mouse and touch event each element saw; `hover.test.mjs` also covers a move the interceptor blocks (`tests/pages/hover-blocked-once.html`), and `tap.test.mjs` runs Playwright's side in a `hasTouch` context and asserts that Playwright's default context refuses `tap` where Neo taps. `goto.test.mjs` runs one script through both engines that describes every `Response` and `Request` value of a 200, a redirect chain, a redirect from the disk cache, a 404, JSON and Latin-1 bodies, `commit` before the body, and the `null` and error answers, decodes each body with Node `Buffer.toString`'s odd arguments, and compares them all; it clears the browser's cache between the turns. `nullOptions.test.mjs` passes `null` as every served method's options and as each schema key, and as a default timeout, and compares how each call settles; `toJSON.test.mjs` compares what JSON makes of a page, frame, context and locator. Where Neo differs on purpose (click `trial` and `noWaitAfter`, `press('Shift+Foo')`, tab activation, the initial `pages()` order), the tests assert each engine's side rather than skip the case. Rejections compare by `errorCategory`: the error's `name`, plus `:strict` for a strict mode violation. The event files (`console`, `dialog`, `pageError`, `waitForEvent`, `consoleMessages` and `eventEmitter.test.mjs`) run each case through Playwright, disconnect it (its server would answer Neo's dialogs too), then run the same script through Neo on a tab loaded before Neo attaches (`events.mjs`); a listener that throws ends Neo's run, a case Playwright's Node process cannot survive, so it runs through Neo alone. The evaluation files (`evaluate*`, `frame-evaluate`, `locator-evaluate*`, `jsHandle-*`, `query`, `evaluateAll`, `evalOnSelector`, `locator-elementHandle`, `getProperty`, `waitForFunction`) compare values through `values.mjs`'s `describe`, so what JSON cannot carry (NaN, -0, undefined, Map, Date, cycles) compares alike in both realms. `harness.mjs` holds what they share, and imports playwright-core itself so colours are off first. The frame tests (`frameLocator`, `contentFrame` and `frames.test.mjs`, and a frame test in each method file) run on `tests/pages/frame-top.html`, a tree of same-origin, cross-site out-of-process and nested frames, through `frames.mjs`, which reads every frame's effect so a call routed to the wrong frame shows as a changed decoy; `NEO_PARITY_REFERENCE_ONLY=1` runs only their Playwright half. They run under Node (Playwright's `connectOverCDP` hangs under Bun), one file at a time, and skip without a browser: `reload`, `goBack`, `goForward` and `waitForNavigation.test.mjs` share `history.mjs`, which launches the browser with Playwright's own `--disable-back-forward-cache` and opens both engines' tabs the same way (about:blank, then the case's page) so their history lists match; they compare responses (status, `ok()`, path), the URL each script ends on and each page's load count. Neo's back-forward cache handling is neo-runtime's `history_e2e.rs`. A URL predicate receives Neo's read-only `URL` (`src/url.ts`).

```sh
NEO_E2E_BROWSER="/Applications/BrowserOS neo.app/Contents/MacOS/BrowserOS neo" bun run test:parity
```
