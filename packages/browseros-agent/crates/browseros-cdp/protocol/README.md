# Protocol inputs

`protocol.json` is the complete, byte-preserved combined protocol generated by
the native Chromium build. Import it with `../sync-protocol.sh`; the script pins
its SHA-256 in `protocol.sha256`. Do not edit either the snapshot or generated
bindings by hand. The shared TypeScript generator must read the same native JSON
through `CDP_PROTOCOL_JSON` so both clients use one wire contract.

`surface.json` selects the Rust APIs compiled by `build.rs`, which also follows
their referenced types across domains. Keeping this selection small controls
compile cost without discarding domains from the committed native snapshot.
Selecting a missing command or type fails generation rather than silently
omitting the requested API.

Profile discovery returns a process-lifetime `BrowserProfileID` for a saved
catalog entry. It can identify an unloaded profile and is invalid after native
restart or catalog removal. `loadProfile` loads that entry without creating a
profile or window; its result `loaded` says whether this call newly loaded it,
while `profile.loaded` describes its current state.

An optional `BrowserProfileInfo.browserContextId` identifies the genuine live
context of a loaded regular profile. Window and tab metadata preserve the legacy
`browserContextId` field and separately expose `browserProfileId` and
`liveBrowserContextId`. Route context-aware creation and History commands with
the genuine live ID, never with the saved handle or legacy metadata field.
