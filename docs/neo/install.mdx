BrowserOS neo is a full browser, so installing it works like installing Chrome or Firefox. Download it, drag it across or run the installer, and open it.

<Columns cols={2}>
  <Card title="macOS" icon="apple" href="https://cdn.browseros.com/download/BrowserOS_neo.dmg">
    Universal build for Apple Silicon and Intel. Requires macOS 10.15 or later.
  </Card>
  <Card title="Windows" icon="windows" href="https://cdn.browseros.com/download/BrowserOS_neo_installer.exe">
    Installer for Windows on x64.
  </Card>
</Columns>

## macOS

<Steps>
  <Step title="Open the disk image">
    Double-click the downloaded `BrowserOS_neo.dmg`.
  </Step>
  <Step title="Drag it to Applications">
    Drag **BrowserOS neo** onto the Applications folder in the same window, then eject the disk image.
  </Step>
  <Step title="Open it">
    Launch BrowserOS neo from Applications or Spotlight. On first launch it will offer to import bookmarks and passwords from your existing browser.
  </Step>
</Steps>

## Windows

<Steps>
  <Step title="Run the installer">
    Double-click the downloaded `BrowserOS_neo_installer.exe` and follow the prompts.
  </Step>
  <Step title="Open it">
    Launch BrowserOS neo from the Start menu.
  </Step>
</Steps>

## Keeping it up to date

BrowserOS neo updates itself. It checks for new versions in the background and installs them on the next restart, so there is nothing to do after the first install.

<Note>
There is no Linux build of BrowserOS neo yet. BrowserOS, the browser for humans, does ship for Linux. See [Install BrowserOS](/browseros) if that is what you are after.
</Note>
