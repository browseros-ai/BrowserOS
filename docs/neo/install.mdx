BrowserOS neo is a full browser, so installing it works like installing Chrome or Firefox. Download it, drag it across or run the installer, and open it.

## macOS

<Tabs>
  <Tab title="Homebrew">
    ```sh
    brew tap browseros-ai/tap
    brew install --cask browseros-neo
    ```

    The tap is needed because BrowserOS neo is not in Homebrew's own cask repository yet. Once it is, the same `brew install --cask browseros-neo` keeps working and the tap becomes optional.

    Upgrade with `brew upgrade --cask browseros-neo`, though the browser also updates itself.
  </Tab>
  <Tab title="Direct download">
    <Steps>
      <Step title="Open the disk image">
        Double-click the downloaded `BrowserOS_neo.dmg`.
      </Step>
      <Step title="Drag it to Applications">
        Drag **BrowserOS neo** onto the Applications folder in the same window, then eject the disk image.
      </Step>
      <Step title="Open it">
        Launch BrowserOS neo from Applications or Spotlight. On first launch it will offer to import bookmarks and passwords from your existing browser.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Windows

<Steps>
  <Step title="Run the installer">
    Double-click the downloaded `BrowserOS_neo_installer.exe` and follow the prompts.
  </Step>
  <Step title="Open it">
    Launch BrowserOS neo from the Start menu.
  </Step>
</Steps>

## Linux

BrowserOS neo ships for both x64 and ARM64 (aarch64) Linux, as an AppImage and as a DEB package. To check which one your computer needs, run:

```sh
uname -m
```

`x86_64` means x64 and `aarch64` means ARM64, for example a laptop with a Snapdragon X processor.

| | x64 | ARM64 (aarch64) |
|---|---|---|
| AppImage | [BrowserOS_neo.AppImage](https://cdn.browseros.com/download/BrowserOS_neo.AppImage) | [BrowserOS_neo-arm64.AppImage](https://cdn.browseros.com/download/BrowserOS_neo-arm64.AppImage) |
| DEB (Debian, Ubuntu) | [BrowserOS_neo.deb](https://cdn.browseros.com/download/BrowserOS_neo.deb) | [BrowserOS_neo-arm64.deb](https://cdn.browseros.com/download/BrowserOS_neo-arm64.deb) |

<Tabs>
  <Tab title="AppImage">
    <Steps>
      <Step title="Make it executable">
        ```sh
        chmod +x BrowserOS_neo.AppImage
        ```

        On ARM64, use `BrowserOS_neo-arm64.AppImage` instead.
      </Step>
      <Step title="Open it">
        ```sh
        ./BrowserOS_neo.AppImage
        ```
      </Step>
    </Steps>
  </Tab>
  <Tab title="DEB">
    <Steps>
      <Step title="Install the package">
        ```sh
        sudo apt install ./BrowserOS_neo.deb
        ```

        On ARM64, use `./BrowserOS_neo-arm64.deb` instead.
      </Step>
      <Step title="Open it">
        Launch BrowserOS neo from your applications menu.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Keeping it up to date

On macOS and Windows, BrowserOS neo updates itself. It checks for new versions in the background and installs them on the next restart, so there is nothing to do after the first install.

On Linux, download the latest AppImage or DEB from the links above and install it the same way. Your profile, sign-ins and settings stay in place.
